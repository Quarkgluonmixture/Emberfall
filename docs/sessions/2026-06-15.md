## Visual + saga legibility pass (acting on the playtest)

Owner directive: leave the mid/late "sleepy macro" (turnover / decisive war)
alone; do the rest of the important findings. So this pass is **all
presentation** — no sim balance touched (growth-pacing was also skipped: it's
the same can't-eyeball balance risk class as the deferred macro work).

- **Territory borders → contours** (`render/territoryLayer.ts`): per-tile neon
  staircase rects replaced with traced boundary loops (unit-segments chained,
  Chaikin-smoothed) stroked as a dark casing + civ-color line. Geometry cached
  per `territoryVersion`; season changes only re-stroke, with winter/autumn
  alpha compensation. Biggest visual win; reads as inked frontiers, not
  spreadsheet cells. Commit 2566501.
- **Saga / Full history** (`ui/historyPanel.ts`, i18n, css): tabs — Saga =
  importance-3 epochal spine (default), Full = + importance-2. Repeated kinds
  within a year collapse to one summary line ("3 wars broke out"). 2566501.
- **Close-zoom icon de-confetti** (`render/citizenLayer.ts`): routine
  farming/gathering citizens show body animation + dust only; overhead action
  icons are reserved for the less-frequent readable states (build/trade/fight/
  flee/rest) and get a soft dark backing. Kills the "yellow wheat confetti."
- **Roads read as infrastructure** (`render/roadLayer.ts`): body alpha
  0.26→0.42 (+level), width base 0.8→1.0/level 0.4→0.5, so trunk routes hold
  against terrain/rivers/borders.
- **Labels** (`render/settlementLayer.ts`): letterSpacing 1→0.4, stroke
  3→3.6 — legible on long names over busy art without a backing plate.
